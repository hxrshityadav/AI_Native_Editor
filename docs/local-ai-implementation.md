## Existing authority and limits

- Root Mediabunny/WebCodecs utilities are not replaced by FFmpeg. Video duration policy is 600 seconds; existing local speech/cleanup tasks are more conservatively capped at 120 seconds.
- `/studio` hosts `/editor/index.html`; OpenReel owns native projects/history/render/export. Legacy migration creates a separate project after fingerprint review and does not overwrite old records.
- Speech worker: Transformers.js 3.8.1 from the existing vendor install, single-thread WASM, same-origin fetch guard, client-owned worker termination on success/error/cancel/unmount, ten-minute idle watchdog. It already returns measured PCM WAV from SpeechT5, and Whisper estimated segment timestamps.
- Cleanup worker: Mediabunny PCM decode, WAV serialization, centre/side DSP and noise-profile spectral subtraction. Codec and mono/stereo/rate/duration validation precedes allocation. Fresh worker per operation bounds retained resources.
- Existing tests include Vitest, real-output Playwright/ffprobe suites, explicit optional model inference and same-origin GET/HEAD privacy checks. Prior results are historical, not a substitute for this change's regression run.

### Shorts architecture and validation

The creator session reuses `runMediaTask` for validation and `runSpeech` for Whisper. Optional ten-minute ASR decodes incrementally into a 16 kHz mono buffer (at most about 38.4 MB of PCM), rather than retaining a full high-rate stereo recording. This is a buffer bound, not a process-RSS measurement. Existing two-minute cleanup/dubbing limits remain unchanged.

Moment suggestions use ordered transcript spans, long gaps, duration, lexical repetition and sentence endings. They are not semantic/viral ranking. Users can correct text/times, select a source range, choose shape and crop, then explicitly store a fingerprinted, expiring local handoff. A new native OpenReel project is built through the existing one-shot conversion adapter. The project/history/render/export engine remains OpenReel; no standalone export or second timeline was introduced.

Studio entry uses a full document navigation so COOP/COEP headers take effect. Only explicit creator entries suppress automatic startup recovery of an unrelated old project; saved projects are retained and normal reload recovery still runs. Source copy writes are confined to a separate handoff DB and a fresh native project/media ID. Failed native saves restore prior in-memory project state and retain the handoff. Expired handoffs are logically rejected after one day and pruned on later handoff activity; no background service worker deletes data.
